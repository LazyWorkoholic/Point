# Point Demo Sample Project

A tiny, deliberately boring project, shipped with Point so Demo mode's
fixtures (B28) have something real to read, list, and edit -- no network,
no live model.

Contents:

- `app.py` -- two small functions (`greet`, `add`) and a `main()`.
- `utils.py` -- two small helpers (`slugify`, `clamp`).
- `web/index.html` + `web/style.css` -- a plain static page.

Nothing here does anything useful on its own. It exists to be read.
